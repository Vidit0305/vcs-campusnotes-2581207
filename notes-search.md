# Notes Search and Filtering

## Overview
The search and filtering feature helps users find their saved notes quickly and easily.
Users can search notes by title or keywords and filter them by category.
## Features

1. **Search Notes:** Users can search notes using their title or keywords.
2. **Filter by Category:** Users can display notes belonging to a selected category.
3. **Combined Search and Filter:** Users can search within a selected category.
4. **No Results Message:** Display a helpful message when no matching notes are found.
5. **Clear Filters:** Allow users to reset the search and category filters.

## Expected Behaviour

- Search results should update according to the entered keyword.
- Category filters should show only relevant notes.
- Search and category filters should work together.
- Clearing filters should display all saved notes again.

## Benefit
This feature improves note organisation and saves users time when locating specific notes.
